## Why

The current dashboard mixes the period selector (year/month) with the data filters (brand, province, cc) in a single flat row. This creates visual confusion: year/month drive a data load while the others filter client-side. Additionally, the new `COMUNIDAD_AUTONOMA` column now available in the CSV is not yet exposed in the UI, making regional analysis impossible from the dashboard.

## What Changes

- **Period selector separated**: Move the year and month selects out of the `.filters` panel into a dedicated `<div class="period-selector">` section that sits above (or alongside) the main filters bar, with visually distinct styling.
- **CCAA filter added**: New "Comunidad Autónoma" `<select>` inserted before the "Provincia" filter. Selecting a community narrows the province dropdown to only the provinces belonging to that community. Clearing the community restores all provinces.
- **CSV parsing updated**: The dashboard now correctly parses the new CSV column order (`MARCA_ITV, MODELO_ITV, PROVINCIA_VEH, COMUNIDAD_AUTONOMA, CILINDRADA_ITV, COUNT`) that the ETL produces since the recent ETL change.
- **Filter logic updated**: `applyFilters()` and `getFilters()` extended to handle the new `comunidad` dimension.
- **Reset button behavior**: Clearing filters resets the CCAA and province selects together; resetting CCAA also resets province.

## Capabilities

### New Capabilities

- `ccaa-province-filter`: Cascading comunidad autónoma → provincia filter in the dashboard.

### Modified Capabilities

- `matriculaciones-dashboard`: Period selector extracted to its own UI section; CSV parsing updated for new column order; filter panel gains CCAA select.

## Impact

- `dgt-matriculaciones-moto/index.html`: All changes contained here (HTML structure, CSS, embedded JS).
- CSV data source: No changes — uses the `COMUNIDAD_AUTONOMA` column already generated by the ETL.
